# 实验 1-1 编译工具链的使用

本关共 4 个子任务，依次熟悉 gcc、clang、交叉编译器 + qemu、make。

## Step 1：gcc 与条件编译（shell1.sh）

**任务**：连编 `def-test.c` 与 `alibaba.c` 生成 `def-test`，让 BILIBILI 相关的 `printf` 生效。

源文件用 `#ifdef BILIBILI` 把对话语句包了起来，需要在编译命令里用 `-D` 选项注入这个宏。

```bash
gcc -DBILIBILI def-test.c alibaba.c -o def-test
```

`-DNAME` 等价于源码里加一行 `#define NAME`，作用于所有翻译单元。

运行结果：

```
Instructor: Hello, I am your instuctor, please introduce yourself.
Bilibili: My name is Bili, 先生お久しぶりです!
Alibaba: My name is Alibaba, I am 24 years old.
Alibaba: Hey Bili, 你娃最近赚钱没得？
```

## Step 2：clang 交叉编译到 ARM 汇编（shell2.sh）

**任务**：用 clang 把 `bar.c` 编译成 ARMv7、Linux、gnueabihf、硬浮点、O2 优化的汇编 `bar.clang.arm.s`。

```bash
clang -S -O2 --target=armv7-linux-gnueabihf -mfloat-abi=hard \
      -Wno-error=implicit-function-declaration bar.c -o bar.clang.arm.s
```

关键选项：
- `-S` 只到汇编阶段
- `--target=armv7-linux-gnueabihf` 指定交叉目标三元组
- `-mfloat-abi=hard` 硬浮点 ABI（参数走 FPU 寄存器）
- `-O2` 优化级别
- `-Wno-error=implicit-function-declaration`：clang 18 把"调用未声明函数"当错误，任务里的 `putint/putch` 没声明，需要降级为警告

**优化效果**（节选）：

```asm
bar:
    mov  r0, #101         @ 整个 bar() 被压缩成一条指令
    bx   lr

main:
    push {r11, lr}
    mov  r0, #101         @ bar() 被完全内联，直接传 101
    bl   putint
    mov  r0, #10
    bl   putch
    mov  r0, #0
    pop  {r11, pc}
```

可以看到三种优化同时发生：常数折叠（`10*10+1 → 101`）、死代码删除（`int b=20` 不见了）、分支删除（`if(a>0)` 消失因为永真）、函数内联（`bar()` 直接代入 main）。

## Step 3：arm-linux-gnueabihf-gcc + qemu-arm（shell3.sh）

**任务**：把 `iplusf.c` 交叉编译到 ARM 可执行，链入 SysY 运行时库 `sylib.a`，用 qemu 运行。

```bash
arm-linux-gnueabihf-gcc -S iplusf.c -o iplusf.arm.s
arm-linux-gnueabihf-gcc iplusf.arm.s sylib.a -o iplusf.arm
qemu-arm -L /usr/arm-linux-gnueabihf/ iplusf.arm
```

三步对应"编译→汇编+链接→运行"。`sylib.a` 是 ARM 32 位的预编译运行时库（`ar t sylib.a` 看到 ELF 32-bit ARM 目标文件）。

`-L /usr/arm-linux-gnueabihf/` 告诉 qemu 用这个 sysroot 找动态链接器和 libc。

> 本地需要先安装 ARM 交叉工具链：`sudo apt install gcc-arm-linux-gnueabihf`

## Step 4：Makefile 构建 helloworld（src/step4/Makefile）

**任务**：写 Makefile 构建 `src/step4/` 下的 C++ 项目，目标二进制 `helloworld`，输出 `Hello world!`。

项目结构：
```
step4/
├── main.cc            # 调 helloworld::say_hello() 后 cout
├── helloworld.cc      # say_hello() 返回 "Hello world!"
├── include/
│   └── helloworld.hh
└── Makefile
```

```makefile
CXX      := g++
CXXFLAGS := -std=c++17 -Wall -O2 -Iinclude

OBJS := main.o helloworld.o

helloworld: $(OBJS)
	$(CXX) $(OBJS) -o $@

%.o: %.cc
	$(CXX) $(CXXFLAGS) -c $< -o $@

main.o:       main.cc       include/helloworld.hh
helloworld.o: helloworld.cc include/helloworld.hh

.PHONY: clean
clean:
	rm -f $(OBJS) helloworld
```

要点：
- 模式规则 `%.o: %.cc` 把所有 .cc 编译为 .o
- `-Iinclude` 让 `#include "helloworld.hh"` 能找到头文件
- 显式列出对头文件的依赖，确保头文件改了 .o 会重新编译
- `clean` 用 `.PHONY` 标记成伪目标

运行：

```
$ make helloworld && ./helloworld
Hello world!
```

# 实验 1-2 SysY 语言与运行时库

## 一、任务描述

熟悉 SysY 语言及其运行时库，用 SysY 实现"买卖股票的最佳时机"：给定数组 `prices[N]`，每个元素是连续 N 个交易日的股价，只允许买入一次卖出一次（且必须先买后卖），求最大利润，无利可图返回 0。

输入接口：`getint()` 读入一个整数；输出接口：`putint()` 输出整数，`putch()` 输出字符。

## 二、SysY 语言要点

SysY 是编译系统设计赛指定的源语言，是 C 的一个**子集 + 少量扩展**。本关涉及的主要约束：

| 特性 | C | SysY |
|---|---|---|
| 类型 | 多种 | 仅 `int` / `float` + 数组 |
| `for` 循环 | ✓ | ✗（只有 `while`） |
| `++` / `--` | ✓ | ✗ |
| `+=` / `-=` | ✓ | ✗ |
| `const` | ✓ | ✓ |
| 多维数组 | ✓ | ✓（按行优先） |
| 字符串 | ✓ | 仅作为运行时库参数（如 `putf` 格式串） |
| I/O | stdio | 由 SysY 运行时库提供 |
| 主函数 | `int main()` | `int main()`，**有且仅一个** |

SysY 不提供 I/O 语言构造，所有输入输出靠 `lib/sylib.c` 里的运行时库函数：

```c
int  getint(void);          // 读一个整数
int  getch(void);           // 读一个字符
int  getarray(int a[]);     // 读一个数组（先读长度再读元素）
void putint(int a);         // 输出整数
void putch(int a);          // 输出字符
void putarray(int n, int a[]);
// 计时：starttime() / stoptime()
```

需要注意 `putch(10)` 表示输出换行（`'\n'` 的 ASCII = 10），`putch(32)` 是空格。

## 三、算法设计

经典做法：**一次遍历 + 维护历史最低价**。

- 遍历数组时，记录到目前为止见过的最低价 `minPrice`
- 当前可获得的利润 = `prices[i] - minPrice`
- 全程最大利润 = max(此值)

时间复杂度 O(N)，空间 O(1)。

不能用 DP 多状态做法（虽然也对），因为本题只允许一次买卖，单变量跟踪足够。

### 算法的 SysY 化改写

C 里常写：

```c
for (int i = 1; i < N; i++) {
    maxP = max(maxP, prices[i] - minPrice);
    minPrice = min(minPrice, prices[i]);
}
```

SysY 没有 `for`/`++`/三目运算符/库函数 `max/min`，需要展开成：

```c
int i = 1;
while (i < N) {
    if (prices[i] - minPrice > maxP) {
        maxP = prices[i] - minPrice;
    }
    if (prices[i] < minPrice) {
        minPrice = prices[i];
    }
    i = i + 1;
}
```

## 四、解法

`task1-2/src/step1.sy`：

```cpp
const int N = 10;
int prices[N];

int maxProfit(int prices[]){
    int minPrice = prices[0];
    int maxP = 0;
    int i = 1;
    while (i < N) {
        if (prices[i] - minPrice > maxP) {
            maxP = prices[i] - minPrice;
        }
        if (prices[i] < minPrice) {
            minPrice = prices[i];
        }
        i = i + 1;
    }
    return maxP;
}

int main(){
    int i = 0;
    while (i < N) {
        prices[i] = getint();
        i = i + 1;
    }

    int best = maxProfit(prices);
    putint(best);
    putch(10);

   return 1;
}
```

### 实现细节

1. **数组参数**：`int maxProfit(int prices[])` 形参不写大小，按 SysY 约定传引用（实际上是首地址传递）。函数内的 `prices` 遮蔽了同名全局数组，但全局 `const int N` 仍可见。

2. **初始 minPrice**：用 `prices[0]` 作为初值，循环从 `i = 1` 开始。这样写比"`minPrice = MAX_INT`"更自然，且 SysY 没有标准库的 `INT_MAX`。

3. **换行**：`putch(10)`。注意题目要求"输出该数值，然后换行"。

4. **main 返回 1**：题目明确要求，与 C 的"通常返回 0 表示成功"不一样，注意别习惯性写成 `return 0`。

## 五、正确性验证（手工演算）

由于本地暂无 SysY 编译器（要等到实验 5/6 才有），只能手工演算。

**例 1：输入 `7 1 5 3 6 4`（取前 6 个，剩余 4 个补 0 不影响）**

| i | prices[i] | minPrice | prices[i]-minPrice | maxP |
|---|---|---|---|---|
| 0 | 7 | 7（初始） | – | 0 |
| 1 | 1 | 1 | -6 | 0 |
| 2 | 5 | 1 | 4 | 4 |
| 3 | 3 | 1 | 2 | 4 |
| 4 | 6 | 1 | 5 | **5** |
| 5 | 4 | 1 | 3 | 5 |

返回 5 ✓

**例 2：输入 `7 6 4 3 1`（递减序列）**

| i | prices[i] | minPrice | prices[i]-minPrice | maxP |
|---|---|---|---|---|
| 0 | 7 | 7 | – | 0 |
| 1 | 6 | 6 | -1 | 0 |
| 2 | 4 | 4 | -2 | 0 |
| 3 | 3 | 3 | -1 | 0 |
| 4 | 1 | 1 | -2 | 0 |

返回 0 ✓

## 六、思考与延伸

1. **SysY 与 C 的关系**：SysY 看似简单，实际是为了让"编译器实现可教学化"——刨掉 C 中复杂特性（指针运算、字符串字面量、复合字面量、变长数组等），只保留最核心的控制流和数据类型，让前端语法和后端代码生成都能在一学期完成。后续实验 5/6 自己写编译器时会深刻体会到这一点。

2. **为什么没有 for**：自顶向下/自底向上语法分析都能轻松处理 `while`，但 `for(init; cond; step)` 三段结构会让 AST 节点设计复杂。砍掉 for 简化前端工作，对源语言表达能力没有实质损失（while 等价）。

3. **运行时库的角色**：SysY 自身只描述"计算"，不描述"I/O"。运行时库 `sylib.a` 是用 C 写的、预编译好的目标文件库，编译器最终生成的目标代码只需要在链接阶段把它链入即可。这与"语言定义"和"标准库"分离是同一个工程哲学。

4. **类型推断小细节**：`prices[i] - minPrice > maxP` 三个变量都是 int，差值仍是 int，比较结果是 0/1 整数（SysY 没有独立的 bool 类型，用 int 表示真假）。

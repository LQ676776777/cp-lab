# 实验 1-4 RISC-V 汇编：冒泡排序

## 一、任务描述

补充完善 RISC-V 汇编文件 `bubble.s` 中的 `bubblesort` 函数，对一个整型数组按升序排序。

主程序（SysY，已给出）的逻辑：
1. 读 10 个整数到数组 `a[10]`
2. 调用 `bubblesort(a, 10)` 排序
3. **用返回值初始化下标 `i`**，遍历输出排序结果

```c
int main(){
    int n = 10;
    int a[10];
    int i = 0;
    while (i < n) { a[i] = getint(); i = i + 1; }
    i = bubblesort(a, 10);     // 注意这里！
    while (i < n) {
        putint(a[i]); putch(32); i = i + 1;
    }
    putch(10);
    return 0;
}
```

**关键约束**：调用方用返回值给循环变量 `i` 赋初值，所以 `bubblesort` 必须返回 0。

## 二、RISC-V 关键知识点

### 2.1 RISC-V 概览

- RISC-V 是开源精简指令集架构（ISA），第五代 RISC
- 寄存器：32 个通用寄存器 `x0`–`x31`，本实验用到的是它们的 ABI 名
- 字长：本实验用 64 位（rv64），但 `int` 仍是 32 位（用 `lw`/`sw` 加载/存储字）

### 2.2 用到的寄存器（ABI 命名）

| 寄存器 | 别名 | 用途 | 谁负责保存 |
|---|---|---|---|
| `x10`–`x17` | `a0`–`a7` | 函数参数/返回值 | 调用者保存 |
| `x5`–`x7`, `x28`–`x31` | `t0`–`t6` | 临时寄存器 | 调用者保存 |
| `x8`–`x9`, `x18`–`x27` | `s0`–`s11` | 保存寄存器 | 被调用者保存 |
| `x1` | `ra` | 返回地址 | 调用者保存 |
| `x2` | `sp` | 栈指针 | 被调用者保存 |
| `x0` | `zero` | 恒为 0 | – |

**调用约定（RV calling convention）**：
- 前 8 个整型/指针参数走 `a0`–`a7`，多余的走栈
- 整型返回值放在 `a0`（必要时 `a0,a1` 一对存 64 位返回值）
- 本函数：参数 `arr` 在 `a0`，参数 `n` 在 `a1`，返回值放回 `a0`

由于我们只用临时寄存器 `t0`–`t6` 和参数寄存器，**不需要保存任何寄存器，也不需要建立栈帧**（无 `addi sp,sp,-N`、`sd ra, ...`），代码直进直出。

### 2.3 用到的指令

| 指令 | 含义 |
|---|---|
| `addi rd, rs, imm` | `rd = rs + imm`（立即数） |
| `sub rd, rs1, rs2` | `rd = rs1 - rs2` |
| `slli rd, rs, n` | `rd = rs << n`（逻辑左移，用来 `*4`） |
| `add rd, rs1, rs2` | 加法 |
| `lw rd, off(rs)` | 从 `rs+off` 处加载 32 位字到 `rd` |
| `sw rs, off(rd)` | 把 `rs` 存到 `rd+off` 处 |
| `bge rs1, rs2, label` | `if rs1 >= rs2 goto label`（有符号） |
| `ble rs1, rs2, label` | `if rs1 <= rs2 goto label`（伪指令，等价 `bge rs2,rs1,...`）|
| `j label` | 无条件跳转（`jal x0,label` 的伪指令） |
| `mv rd, rs` | 复制（`addi rd,rs,0` 伪指令） |
| `li rd, imm` | 加载立即数（伪指令） |
| `ret` | 返回（`jalr x0, 0(ra)` 伪指令） |

### 2.4 数组寻址

C 里的 `arr[j]` 在汇编里要手算地址：

```
&arr[j] = arr_base + j * sizeof(int) = a0 + (j << 2)
```

所以模式是：

```
slli  t4, t1, 2          # t4 = j * 4
add   t5, a0, t4         # t5 = &arr[j]
lw    t6, 0(t5)          # t6 = arr[j]
lw    a2, 4(t5)          # a2 = arr[j+1]    ← 直接 +4 偏移取下一个
```

## 三、算法：冒泡排序

```c
int bubblesort(int *arr, int n) {
    int i = 0;
    while (i < n - 1) {
        int j = 0;
        while (j < n - 1 - i) {
            if (arr[j] > arr[j+1]) {
                int t = arr[j]; arr[j] = arr[j+1]; arr[j+1] = t;
            }
            j = j + 1;
        }
        i = i + 1;
    }
    return 0;
}
```

时间复杂度 O(n²)，空间 O(1)，最坏/平均/最好都是 O(n²)（这里没做"无交换则提前退出"优化，与给定模板风格一致）。

## 四、寄存器分配

| 寄存器 | 含义 |
|---|---|
| `a0` | arr 首地址（参数）→ 退出时设为 0 作返回值 |
| `a1` | n（参数） |
| `t0` | 外层 i |
| `t1` | 内层 j |
| `t2` | 常量 `n - 1` |
| `t3` | 内层上界 `n - 1 - i` |
| `t4` | `j * 4`（地址偏移） |
| `t5` | `&arr[j]` |
| `t6` | `arr[j]`（用于交换） |
| `a2` | `arr[j+1]`（用于交换） |

## 五、解法

`task1-4/src/bubble.s`：

```asm
        .text
        .align  1
        .globl  bubblesort
        .type   bubblesort, @function
bubblesort:
        addi    t2, a1, -1          # t2 = n - 1
        li      t0, 0               # i = 0
.L_outer:
        bge     t0, t2, .L2         # i >= n-1 时跳出
        sub     t3, t2, t0          # t3 = n - 1 - i
        li      t1, 0               # j = 0
.L_inner:
        bge     t1, t3, .L_inc_i    # j >= n-1-i 时跳出内层
        slli    t4, t1, 2           # t4 = j * 4
        add     t5, a0, t4          # t5 = &arr[j]
        lw      t6, 0(t5)           # t6 = arr[j]
        lw      a2, 4(t5)           # a2 = arr[j+1]
        ble     t6, a2, .L_inc_j    # 升序就跳过交换
        sw      a2, 0(t5)           # arr[j]   = old arr[j+1]
        sw      t6, 4(t5)           # arr[j+1] = old arr[j]
.L_inc_j:
        addi    t1, t1, 1
        j       .L_inner
.L_inc_i:
        addi    t0, t0, 1
        j       .L_outer
.L2:
        li      a0, 0               # 返回值
        ret
        .size   bubblesort, .-bubblesort
```

### 实现细节

1. **不建立栈帧**：因为没调用其它函数（没有需要保存的 `ra`），也没用到 callee-saved 寄存器（`s*`），栈指针 `sp` 全程不动。
2. **分支条件取反**：C 里写 `while (i < n-1)`，汇编里通常取反成 `if (i >= n-1) break`，对应 `bge t0, t2, .L2`。这是汇编里写循环的常用模式。
3. **`ble` 是伪指令**：编译器最终会展开成 `bge a2, t6, .L_inc_j`（比较顺序对调），意义不变。
4. **返回值 0**：`li a0, 0` 显式置零，配合 `ret`。

## 七、思考与延伸

1. **为什么用 `lw`/`sw` 而不是 `ld`/`sd`**：RV64 上 `int` 是 32 位，要用字（word）粒度的访存指令 `lw`（load word，符号扩展到 64 位）和 `sw`（store word，存低 32 位）。`ld`/`sd` 是 8 字节粒度，会越界。

2. **`a2` 也是 caller-saved**：本函数虽然把 `arr[j+1]` 暂存到 `a2`，但调用结束前不会跨过任何函数调用，调用者也不指望 `a2` 保留入参以外的值，所以可以放心当临时用。

3. **如果加上"无交换则提前退出"优化**：内层循环加一个标志位寄存器 `t1_swapped`，每次交换置 1，外层结束后若为 0 直接 `j .L2`。最好情况（已升序）就能 O(n) 退出。这是面试常考的优化点。

4. **`slli rd, rs, 2` vs `mul`**：`slli` 比 `mul` 快得多（移位是单周期，乘法是多周期甚至需要乘法器扩展），用移位代替"乘以 2 的幂"是经典优化，编译器也会自动这么做。

5. **与 ARM 对比**：同样的逻辑在 ARM 上对应的指令是 `LDR`/`STR`/`LSL`/`CMP`/`B.GE` 等，核心模式一致。RISC-V 指令更"正交"（每个指令格式简单），少特殊编码，这是它"精简"的体现。
